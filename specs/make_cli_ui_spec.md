### Construção de uma cli ui


# Função

Você deve utilizar a biblioteca rich text para criar a ui totalmente em cli, a ideia é se tratar de uma especie de chat cli onde o usuario ira receber repostas podendo ser codigos fontes ou simples texto.

A ui deve seguir um estilo predominantemente com a cor roxo e limpo, com base em alguns comandos do usuario também deve ser possivel abrir menus/modais em formato cli

Todo codigo desenolvido para a criação da ui cli, deve estar dentro da pasta @cli, sendo divido em components por exemplo chat_input, chat_output.

Sempre coloque comentarios sobre o codigo desenvolvido para facilitar a compreensão e manutenção.
